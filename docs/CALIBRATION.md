# 驗證與校準

怎麼知道 `core/recommend.py` 的評分真的有用？怎麼調權重才不是自欺欺人？

## 先講最重要的一件事

**單一 as_of 日期的復盤結果，不足以拿來調權重。**

跑一次 `--asof 2026-08-01`，看到 40 檔美股、相關係數 0.3，很容易以為「有
40 個樣本，統計上還可以」。實際上不是：這 40 檔在同一個市場、同一段期間，
彼此高度相關。大盤那七週漲，它們大多漲；大盤跌，它們大多跌。**有效樣本數
接近 1（一個市場環境），不是 40。**

依據一個樣本調權重，調出來的是那七週的噪音，不是規律。下一段行情就失效。

## 三個問題，依序回答

### 問題一：評分有沒有勝過「不選股」？

這是最低標準，`/review` 頁面現在直接給你答案：

```
對照基準（整池 40 檔等權、完全不選股）+9.20%　→ 超額報酬 -1.30%（輸給不選股）
```

**沒有這個對照，平均報酬 +7.9% 這個數字毫無意義。**大盤漲 9.2% 的期間，
選股選出 7.9%，代表評分是負貢獻 —— 你不如整池買下去。

留意一個容易誤判的情況：超額報酬為正，但相關係數為負。這代表你「選對池子、
排錯順序」—— 篩掉爛股有效，但前 N 名的排序沒有意義。這時該做的是調整
`min_score` 門檻，而不是動因子權重。

### 問題二：訊號來自哪個因子？

`factor_ic` 給每個因子各自的相關係數：

```
逐因子 IC：
  trend       +0.18
  momentum    +0.11
  volume      -0.04
  position    -0.09
  volatility  +0.02
```

這才是調權重的依據。上面這組結果的讀法：趨勢和動能在出力，位階在扯後腿，
量能和波動基本上是噪音。

**IC 的合理範圍**：單一時間橫斷面的 IC，實務上 0.05~0.15 就算不錯，
0.3 以上要先懷疑是不是哪裡偷看到未來資料。看到 0.9 幾乎可以確定有 bug
（或者你的樣本只有三檔）。

### 問題三：這個結論在別的時間點還成立嗎？

這是唯一能區分「規律」和「噪音」的方法：**換好幾個 as_of 日期重跑，
看 IC 的正負號穩不穩定。**

```bash
for d in 2025-03-01 2025-06-01 2025-09-01 2025-12-01 2026-03-01 2026-06-01; do
  python cli.py review --market US --asof "$d" --until "$(date -I -d "$d + 90 days")" --json \
    > "review_US_$d.json"
done
```

一個因子要在 6 個以上不同時期都維持同方向的 IC，才值得相信。
只要有一半時期符號翻轉，那個因子就是噪音，權重應該調降甚至歸零。

## 會讓你被騙的四個陷阱

### 1. 生存者偏誤（最嚴重，而且目前無解）

`config/universe/*.txt` 是**今天**的大型股清單。2025 年 8 月表現慘烈、
已經跌出權值股行列的股票，根本不在這份清單裡。

拿今天的贏家清單回測過去，結果必然偏樂觀 —— 你等於預先知道了哪些公司
活下來。**這會讓復盤結果整體偏好，沒有簡單的修法**，需要有歷史成分股
資料（每個時間點的實際清單）才能真正解決。

在有歷史成分股之前：**把復盤結果當成「相對比較」而不是「絕對績效」**。
因子之間的 IC 高低比較仍然有參考價值（偏誤對所有因子一視同仁），
但「平均報酬 +12%」這個絕對數字不要當真。

### 2. 台股沒有還原權息

免費 FinMind token 拿不到還原股價，會退回未還原資料（程式會警告）。
未還原的價格在除息日會憑空跳空下跌，導致：

- 高殖利率股的報酬被系統性低估
- 除息跳空可能被誤判成破位

**台股的復盤結果在拿到贊助會員 token 之前，可信度明顯低於美股。**

### 3. 多重測試

試 20 組權重，挑報酬最好的那組 —— 你找到的是噪音。這在統計上叫
data snooping，是量化最常見的自欺方式。

紀律：**先決定要改什麼、為什麼改，再去驗證**。不要跑一堆組合挑最好的。
如果真的要比較多組設定，最後一定要用一段從沒看過的期間做最終驗證。

### 4. 樣本外驗證

把時間軸切成兩段：

- **調整期**（例如 2024 全年）：在這段上看 IC、調權重
- **驗證期**（例如 2025 全年）：**只跑一次**，看調完的權重在這段有沒有效

驗證期跑第二次、再回頭調權重，它就不再是樣本外了。這條紀律很難守，
但不守的話整個驗證就是裝飾。

## 實際操作順序

1. **先跑一次美股**（資料品質最好、成本 0bps、沒有 T+1）
   ```bash
   python cli.py review --market US --asof 2026-08-01
   ```
   看超額報酬和 factor_ic。這是基準線。

2. **換 5~6 個 as_of 日期重跑**，記錄每次的 factor_ic。

3. **找出符號穩定的因子**。只有在多數時期都同方向的因子，才動它的權重。

4. **一次只改一個權重**，幅度不要超過現值的一半。改完重跑同一批日期，
   確認超額報酬有改善。

5. **台股和 A 股分開驗證，不要共用權重結論**。市場結構差異很大（成本
   58.5bps vs 0bps、有無漲跌停、T+1），美股有效的因子在台股未必有效。
   `config/markets.yaml` 目前是三市場共用同一組 `score` 權重 ——
   如果驗證顯示各市場的有效因子不同，這裡需要改成分市場設定。

## 目前做不到、但該知道的

- **持有期間的出場規則沒有模擬**。現在的復盤是「買進、放到 until、賣出」，
  完全不管中間 P6/P8 觸發停損。真實操作會提早出場，結果會不一樣。
  這需要逐條規則回測（`CLAUDE.md` 待辦第一項）。
- **沒有滑價與流動性模型**。只扣了來回手續費與稅。小型股實際成交價會更差。
- **沒有分批進出場**。假設單日一次買足、一次賣完。
- **沒有交易日曆**。跨市場的日期對齊有誤差，特別是連假前後。
